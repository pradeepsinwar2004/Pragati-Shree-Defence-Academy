# 🏫 Pragati Shree Defence Academy Website

This is a static website built using **HTML, CSS, and JavaScript** to showcase the courses, values, and contact information of **Pragati Shree Defence Academy** — an institute dedicated to training future defence personnel.


---

## 📁 Project Structure

Pragati-Shree-Defence-Academy/ ├── index.html ├── about.html ├── contact.html ├── courses.html ├── gallery.html ├── css/ │ └── style.css ├── js/ │ └── script.js ├── images/ │ └── (all your assets) └── README.md


---

## 🎯 Features

- Fully responsive design
- Clean and informative UI
- Image gallery
- Course listings
- Contact form (UI only)
- Easy to modify and expand

---

## 🚀 How to Use

1. **Download or clone** the repository.
2. Open `index.html` in any browser.
3. All pages are internally linked and work offline.

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
